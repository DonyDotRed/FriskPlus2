# GM Frisker Lab v1.4 Advanced Mobile

**GM-Frisker 방사능·표면오염도·MDA·단위변환·공간역산·측정불확도 교육용 웹 시뮬레이터**

## 시작하기

**로컬 환경:** ZIP 압축 해제 → `index.html` 더블클릭 → 비밀번호 `redpass` 입력 → 계산. 데스크톱·스마트폰 브라우저에서 사용 가능하며 별도 서버, 패키지 설치, 외부 JavaScript 라이브러리가 필요 없다. 수식·근거 상세안내는 `manual.html`에서 별도로 읽을 수 있고, 프로그램의 **수식·사용 안내** 메뉴에서 연결된다.

**GitHub Pages:** 빈 GitHub 저장소 생성 → `index.html`, `manual.html`, `.nojekyll`을 저장소 최상위(root)에 업로드 → **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, Folder: /(root)** 선택 → 사이트 주소 접속. 이미 기존 `index.html`이 있는 경우, 작업 전 백업 권장. GH Pages 배포 반영까지는 GitHub의 작업 처리 상태에 따라 달라질 수 있다. 배포 후 두 페이지와 비밀번호, 저장/다운로드 동작을 직접 확인한다.

**참고:** `standalone.html` 또는 `index.html` 한 파일만으로도 주요 계측·시뮬레이션 기능은 실행되지만, 별도 해설 페이지로 이동하려면 `manual.html`을 같은 폴더에 둬야 한다.

## 유지되는 v1.3 기능

- 총/순 계수율, 방사능, 표면오염도, 면적·효율 검증, 표시값 오류 탐지.
- NUREG/Currie 근사, 시간비대칭·가변 α/β 정규근사, **배경 평균을 아는** 기존 Poisson 모드.
- 검출가능성·MDA/MDC 곡선, 필요 계수시간, 정지계측 모델 비교.
- 가상 점·면·집중·다지점 오염지도, 클릭/터치로 프로브 위치 이동.
- 단일 hotspot과 36셀 비음수 정규화 공간역산.
- 기존 독립 GUM 불확도, 독립 Monte Carlo, 장비 교정/핵종/재질 입력 및 경고.
- 19개 방사선·방사능 단위 물리량, 127개 단위의 변환센터와 조건부 계산기.
- JSON 저장/불러오기·CSV·PNG·보고서 인쇄, 7종 테마, 글자/줄간격, 모바일 5개 하단 메뉴 및 더보기, 간단 비밀번호.

## 안전성과 모델 범위 (중요)

1. **정적 GitHub Pages의 비밀번호 확인은 암호학적으로 안전한 접근통제가 아니다.** 브라우저에 전체 자바스크립트가 전송되어 우회 가능하다. 기밀·개인정보·민감 실측자료를 저장소에 올리지 말 것. 인증이 필요하면 Cloudflare Access/서버측 인증/비공개 배포 등 별도 서비스 필요.
2. **실측 교정자료 없는 GM-Frisker 상대효율·핵종·표면·거리 보정은 교육용 가정값**이다. 사용자 정의 K와 교정상태를 확인하지 않으면 공식 방사능 판정 불가.
3. **피부·의류는 ISO 7503-1:2016의 적용 범위 밖**이므로 일반 표면오염 효율을 그대로 전용하지 말 것.
4. 기존 **정지계측 MDA**와 새 **스캔 근사 MDC**는 다른 측정 상황이다. 특히 스캔 근사는 NUREG-1507의 모든 반응·관찰자 성능을 구현한 정식 결과가 아니다. 배경 0 또는 극저계수에서 정규 기반 스캔 모델은 부적절하며 0 배경은 차단한다.
5. 공간 역산의 낮은 잔차는 실제 공간분포가 유일하게 확인됐다는 의미가 아니다. 입력 미지수 수, 교정 커널, 측정기 응답의 식별성을 따로 검토할 것.
6. Monte Carlo **모형반복 초과분율은 Bayesian 사후확률이나 기준 적합도 확률이 아니다.** 반복 시뮬레이션에서는 관찰 계수율을 미래 모의계수의 평균으로 대입한다.
7. 저계수율 exact 2표본은 일정 독립 Poisson 가정과 알려진 계획 배경 평균을 이용한 **사전 검출력 계산**이다. 공식 ISO 11929 적합 판정으로 오용하지 말 것.

## CSV 데이터 예제

```csv
x_cm,y_cm,gross_cpm
-5,-5,69
0,-5,90
5,-5,75
-5,0,80
0,0,180
5,0,92
-5,5,71
0,5,83
5,5,67
```

헤더 포함·미포함 모두 입력 가능. 지점 CSV는 250행 이하. 계수시간·기기·교정식은 해당 CSV에 포함되지 않으므로 앱의 설정값을 별도로 확인해야 한다.

## 화면 메뉴와 빠른 사용

- 하단 **계산**: 기본 계측, 빠른 예제, 주요 KPI. 여기서 MDA·시나리오·불확도·수식 안내로 바로 이동.
- 하단 **MDA**: 기존 결정임계값/MDA 요약 및 저계수율 2표본·스캔 근사.
- 하단 **시나리오**: 점·면·집중·2점·피부·의류 프리셋, 가상 프로브 cpm 프로파일, 화면 하단 기존 오염지도.
- 하단 **변환**: 방사선·방사능 단위 변환.
- **더보기**: 공간 분석, 불확도, 교정, 보고서, 수식·근거·사용 안내.
- 상세 안내서: `manual.html` 직접 열거나 프로그램 내 **수식·사용 안내**에서 열기.

## 버전 호환성 및 저장

기존 v1.3 브라우저 로컬 저장 키(`gm-lab-project-v11`, `gm-lab-prefs-v11`)를 재사용하므로 현재 로컬 프로젝트를 불러올 수 있다. JSON의 `version` 표기는 v1.4로 갱신했다. 새 추가 분석 설정(상관 ρ, 별도 d′ 등)은 기본값에서 시작하며 v1.3 프로젝트 형식에 새로운 필드가 없더라도 기존 내용이 유지되도록 구현했다. **브라우저의 로컬 저장은 계정동기화가 아니므로 JSON 파일로 정기 백업**할 것을 권장한다.
