GM Frisker Lab v1.4 — 계산 수식·물리 모델·통계·근거 안내서

목적: GM-Frisker 계수자료를 이용한 방사능·표면오염도 계산, MDA/MDC, 시나리오/공간역산, 불확도와 모델 진단을 교육·연구 목적으로 수행한다. 실제 측정기·핵종·매질·거리·교정·품질보증이 검증되지 않은 결과는 법적 적합성·반출·제염 종료의 단독 근거로 사용할 수 없다.

버전: 1.4 / 2026-11-24. 이 문서는 개념 설명 및 구현 수식의 출처 안내다. 표준 원문을 대체하거나 ISO 규격 적합성을 보증하지 않는다.

1. 1분 사용 가이드

  1. 웹에서 index.html 열기 → 편의용 비밀번호 redpass 입력. 정적 페이지 보호는 아님.
  2. 계산 탭: 측정기 총계수율·배경계수율, 총/배경 계수시간, 교정 유효응답 K, 오염면적을 확인한다. 가급적 원시 counts 입력 및 실측 확인을 사용한다.
  3. MDA 탭: 계측조건별 정지계측 MDA/MDC, 목표 검출능력에 필요한 시간, 2표본 Poisson 모델, 스캔 근사를 구분해 본다.
  4. 시나리오 탭: 점·면·집중·2점 오염형상 예제를 고르고, 지도에서 프로브 위치를 이동하며 예상 계수율 변화를 확인한다.
  5. 공간분석 탭: 3×3/5×5 모의 자료를 생성하거나 CSV로 측정점을 불러와 단일 hotspot 또는 36셀 비음수 역산을 실행한다. 잔차와 해의 비고유성 경고를 확인한다.
  6. 불확도 탭: 계수통계·응답계수·면적·배경 변동을 입력하고 95% 정규근사와 모델 반복(Monte Carlo)의 차이를 확인한다.
  7. 변환 탭은 물리량이 같은 단위끼리 환산하며, cpm→Bq는 반드시 별도 유효응답을 지정한다.

2. GM 계수율과 방사능의 관계

독립된 총계수와 배경계수를 N_g, N_b, 각각 계수시간을 t_g, t_b라고 하면

r_g = N_g / t_g                   [cps]
r_b = N_b / t_b                   [cps]
r_net = r_g − r_b                [cps]
A_hat = r_net / K                [Bq]
a_s,hat = A_hat / S              [Bq/cm²]
  • K는 cps/Bq 단위의 유효응답이다. 별도의 기기효율과 선원효율의 곱으로 산출했으면 그 조건과 교정의 유효성을 확인해야 한다.
  • S는 산출 대상 오염 평가면적이고 15.5 cm²의 검출기 창 면적을 무조건 대입할 수 없다.
  • 음의 순계수는 측정통계상 가능하므로 보존해야 한다. 표현상 물리 방사능 0 이상 표시와 음의 통계 추정치를 혼동하지 않는다.
  • 총계수율 3.0 cps가 순계수율 2.0 cps로 바뀌려면 배경 1.0 cps를 차감해야 한다.

효율 중복 보정을 피하려면

ε_i와 ε_s가 서로 구분된 적절한 독립 성분이며 단일 방출률에 대한 모델을 적용하는 경우 K ≈ ε_i ε_s × 방출확률 등을 사용할 수 있다. 이미 직접 교정된 K에 별도로 효율을 다시 곱하지 않는다. 실제 베타/알파 검출효율은 핵종, 방출강도, 표면상태, 거리, 검출창, 감도변화에 좌우된다.

3. 계수통계와 실제 측정시간

Poisson 계수 N ∼ Poisson(λt)는 평균과 분산이 동일한 모형이다. 독립 계수를 가정하면

Var(r_net) = Var(N_g/t_g) + Var(N_b/t_b)
           ≈ N_g/t_g² + N_b/t_b²
u_stat(A_hat) = sqrt(N_g/t_g² + N_b/t_b²) / K

예를 들어 N_g=180, N_b=60, t_g=t_b=60 s이면

u(r_net) = sqrt(180/60² + 60/60²) = 0.258199 cps
u_stat(A) = 0.258199 / 0.2 = 1.2910 Bq
u_stat(a_s) = 1.2910 / 15.5 = 0.08329 Bq/cm²

기기에 표시된 cpm이 실제 원시계수와 반드시 일치하지는 않는다. 계기시정수·평활화·롤링 평균·dead time·오버로드 등이 있으면 위 Poisson 모델 적용성이 제한된다. 원시 계수와 실제 시간, 독립적인 배경계수를 확보하는 것이 바람직하다.

4. Lc, Ld, MDA, MDC: 서로 다른 통계 개념

항목 표기 의미 사용 시점
결정임계값 Lc 또는 y* 현재 관측 계수가 배경 가설을 초과한다고 판단하는 기준 관측 후 검출 판정
검출한계 Ld 또는 y# 미검출 위험 β를 통제하며 탐지할 수 있는 참 신호 수준 방법 사전 설계·능력
최소검출가능방사능 MDA Ld를 유효응답과 시간으로 나눈 방사능 방법 민감도
최소검출가능오염도 MDC MDA를 타당한 평가면적으로 나눈 평균 표면오염도 면적별 민감도 
MDA = Ld / (K t_g)                 [Bq]
MDC = MDA / S                      [Bq/cm²]

MDA는 개별 관측값의 검출 판정선이 아니다. 계수 판정은 Lc 또는 해당 모델의 정확 검정 p값으로 한다. 또한 MDA보다 낮은 실제 방사능도 일정 확률로 검출될 수 있다. ISO 11929는 결정임계값·검출한계·포함구간의 체계를 다루지만, 여기 제시한 모든 근사 수식이 ISO의 정식 계산절차와 동일하다는 의미는 아니다.

5. 정지계측 MDA 대표 근사: Currie/NUREG와 일반화

총·배경 계수시간이 같고, 평균 배경 계수 B = r_b × t일 때 자주 쓰는 5%/5% 근사:

Lc ≈ 1.645 sqrt(2B)                 [net counts, approx]
Ld ≈ 3 + 4.65 sqrt(B)               [net counts, approximate NUREG/Currie convention]
MDA ≈ [3 + 4.65 sqrt(B)] / (K t)     [Bq]

입력 예제에서는 B=1 cps × 60 s=60 counts이므로

Ld = 3 + 4.65 sqrt(60) ≈ 39.019 counts
MDA = 39.019 / (0.2 × 60) ≈ 3.2516 Bq
MDC = 3.2516 / 15.5 ≈ 0.2098 Bq/cm²

서로 다른 계수시간에서 배경 변동을 반영하는 근사의 기초분산은

V0 = (r_b t_g) [1 + (t_g/t_b)]          [counts²]
Lc ≈ z_(1−α) sqrt(V0)                  [net counts]

v1.3의 3+3.29√V0 방식 및 신호분산을 반영한 정규모델은 서로 다른 근사이므로 반드시 모델명을 확인한다. 본 프로그램의 5%/5% 고정 근사 선택 시 α·β 사용자 입력을 적용하지 않는다. 특히 배경 계수가 작으면 이산 Poisson 접근과 차이가 커진다.

6. 저계수율 — 두 종류의 Poisson 계산을 구분하기

6.1 배경 평균을 완벽히 아는 1표본 Poisson 모델

미리 정확히 알려진 배경 기대계수 B에 대해 정수 검출 경계 c를 설정한다.

c = smallest integer such that P(N_g >= c | mean=B) <= α
Find signal Ld such that P(N_g >= c | mean=B+Ld) >= 1−β
MDA = Ld / (K t_g)

배경 평균이 독립 계수측정으로 추정됐다면 이 근사는 그 불확도를 누락한다.

6.2 배경을 독립적으로 측정하는 2표본 Poisson 고급 모델

총계수 N_g와 배경 N_b를 각각 Poisson으로 가정하고, 배경만 존재하는 귀무가설 H0: λ_g=λ_b에서는 총계수 N=N_g+N_b로 조건부화한다.

N_g | (N_g+N_b=n), H0 ~ Binomial(n, p0)
p0 = t_g / (t_g + t_b)
p_value = P[Binomial(N_g+N_b, p0) >= N_g]

각 배경계수 j에서 가장 작은 총계수 임계값 c(j)를 찾고, 사전에 가정한 배경 기대계수 μ_b=r_b t_b의 Poisson 분포를 사용해 탐지확률을 산출한다.

P_detect(A) = Sum_j P(N_b=j | μ_b) × P(N_g>=c(j) | r_b t_g + A K t_g)
MDA_exact = smallest A ≥ 0 such that P_detect(A) ≥ 1−β

이 경우 α 제어는 조건부 검정을 통해 달성되며 실제 오검출률은 이산성 때문에 α보다 작을 수 있다. 계산은 배경 기대계수(총·배경) 각각 70 이하에서만 제공한다. 이 방식은 연구·교육용 구현이며 ISO 11929의 모든 요구조건을 직접 구현한 것으로 주장하지 않는다. 모형은 일정·독립 배경, Poisson 적합성 및 교정 유효성을 가정한다.

예시: t_g=t_b=60s, r_b=1cps, K=0.2cps/Bq, α=β=5%일 때 2표본 정확 모델은 약 3.55 Bq의 MDA를 줄 수 있으며, 동일 예제의 3.25 Bq 근사와 차이가 생긴다. 정확 결과는 실행한 계산 및 반올림 설정을 따른다.

7. 스캔 MDC — 정지계측과 물리적으로 다른 문제

현장에서 프로브를 이동할 때 오염물 위에 머무르는 유효시간, 감도함수, 시정수, 스캔속도, 관찰자의 판단이 중요해진다. v1.4는 사용자 지정 d′와 K_scan을 사용하는 교육용 민감도 근사를 제공한다.

τ = scan_width / scan_speed                 [s]
b_τ = r_b × τ                               [counts]
MDCR_net ≈ d′ sqrt(b_τ)                    [net counts, normal approximation]
MDA_scan,approx = MDCR_net / (K_scan τ)     [Bq]
MDC_scan,approx = MDA_scan,approx / S       [Bq/cm²]

입력 예제 r_b=1cps, scan_width=5 cm, scan_speed=3 cm/s, K_scan=0.2 cps/Bq, d′=2.32, S=15.5 cm²이면 τ=1.667s, b_τ=1.667counts, MDA≈8.99Bq, MDC≈0.580Bq/cm²이다. 배경 기대계수가 5 미만인 이 예제는 정규 근사의 정확성이 떨어진다. 결과는 교육용 민감도 설명에 한정한다.

이 프로그램은 다음을 모형화하지 않는다: 실제 기기 시정수, 경보로직, 관찰자 피로/인지, 모션 블러, 프로브-표면 간 거리의 공간변화, 여러 핵종의 비율과 차폐, 정확한 NUREG-1507 스캔 MDC 절차. NUREG-1507과 ORISE 계산기의 상세 스캔 모델을 참조해 별도 현장 검증해야 한다.

8. 오염형상·표면재질·검출기의 정방향 모델

실제 오염이 연속적이면 검출기 응답의 정방향모델은 다음 적분식으로 나타낼 수 있다.

r_net(x_p,y_p) = ∬ a(x,y) × k(x,y ; x_p,y_p,E,material,d) dx dy
  • a(x,y): 실제 방사능 면밀도 Bq/cm²
  • k(...): 해당 위치의 단위 방사능에 대한 검출 감도, 표면효율·핵종·거리·각도·검출창을 포함한 응답함수
  • x_p,y_p: 검출기 중심 위치

v1.4의 교육용 장에서는 감도커널을

k_rel(Δx,Δy) = exp( −(Δx² + Δy²) / (2σ_k²) )
r_net,pred = K × F × Sum_j [ A_j × k_rel(x_j−x_p,y_j−y_p) ]

와 같이 단순화한다. 이 커널은 임의의 가정이며 실제 판케이크 GM 검출기의 물리학적 응답함수를 대체하지 않는다. F는 사용자가 정의한 상대응답 보정값이며, 철재·플라스틱·피부·의류라고 선택해도 프로그램이 신뢰 가능한 보정값을 자동 생성하지 않는다.

사용자가 바꿀 수 있는 시나리오는 점오염, 균일 면오염, 중심이 집중된 가우시안 hotspot, 2개 오염원의 혼합이다. 2D 지도의 활동도 분포는 정규화되어 총 방사능이 입력값과 일치하도록 구성한다. 지도에서 위치를 선택하거나 x방향 횡단 프로파일을 보면 오염 위치와 최대계수 위치가 반드시 일치하지 않을 수 있음을 확인할 수 있다.

피부·의류 주의

ISO 7503-1:2016은 피부·의류·이동성 물질을 적용범위에서 제외한다. 피부의 땀·피지, 의류 섬유 사이 오염, 랩핑, 창 앞 공기층 등의 영향을 고려하지 않은 효율을 그대로 적용하는 것은 부적절하다. 피부·의류 시나리오는 통상적인 표면오염 교정값의 타당성을 검토하는 교육용 비교다.

9. 다지점 공간 역산, 식별성, 잔차

측정위치가 i=1,…,m, 격자 오염변수가 j=1,…,n이면 다음 선형 방정식을 생각할 수 있다.

y_i = r_i,gross − r_i,background = Sum_j H_ij A_j + ε_i
H_ij = K F × kernel(source cell j, probe location i)

기존 엔진의 두 옵션은 단일 hotspot 모델(위치 x,y와 A 추정) 또는 36셀 비음수 정규화 모델이다.

Minimize_A>=0 [ ||H A − y||² + λ ||A||² ]

이는 엄밀한 Poisson 최대우도 추정과 다르며 가정한 정규화 λ와 커널σ에 민감하다. 관측점 9개로 36개 격자 활동도를 유일하게 복원할 수 없다는 사실은 잔차가 낮더라도 변하지 않는다. 시뮬레이터는 다음 진단을 제공한다.

Residual_i = measured_gross_cpm_i − predicted_gross_cpm_i
RMSE = sqrt[ Sum_i Residual_i² / m ]
MAE  = Sum_i |Residual_i| / m
R²   = 1 − SSE / SST   (SST>0인 경우)

주의: R²는 학습자료에 대한 기술통계이며 위치·활동도 추정의 신뢰수준 또는 불확도를 뜻하지 않는다. 교정커널 오차·위치 측정오차·스캔시간 누락·비균일 배경을 반영하지 않는다. 모의점은 단순 격자 기대값 또는 Poisson 모의 계수로 생성하며, 실제 측정값으로 위장하지 않는다.

10. 측정불확도 예산: GUM 선형화 모델

오염도 a = (r_g−r_b)/(K S)에 대해, 오차요인의 독립성을 일부 완화하고 응답 K와 면적 S의 상대 표준불확도에 상관계수 ρ를 적용한다.

u_count(a) = sqrt(r_g/t_g + r_b/t_b) / (K S)
u_K(a)     = |a| × u_rel(K)
u_S(a)     = |a| × u_rel(S)
u_drift(a) = u_drift,cpm / (60 K S)

u_c²(a) ≈ u_count² + u_K² + u_S² + u_drift² + 2ρ u_K u_S
U_95,normal ≈ 1.96 × u_c(a)

K와 S 모두 분모로 존재하므로 두 민감도계수는 음수이며, ρ가 양수이면 분산 공분산항은 양수다. ρ<0인 경우 일부 변동이 상쇄될 수 있지만 실제 공분산에 대한 교정 근거가 필요하다.

기존 독립모델에서 표면오염도의 계수통계 표준불확도는 약 0.08329 Bq/cm²이며, u_rel(K)=15%, u_rel(S)=0%라면

u_K(a) = 0.645161 × 0.15 = 0.096774 Bq/cm²
u_c(a) ≈ sqrt(0.08329² + 0.096774²) = 0.1277 Bq/cm²
95% 정규근사 ≈ 0.6452 ± 1.96×0.1277 Bq/cm²

95% 정규근사 구간이 실제 규제기준 적합성의 95% 확률을 의미하지는 않는다. 편의상 산출한 k=1.96 근사는 소계수·높은 상대 불확도·경계값 근처에서는 적절하지 않을 수 있다.

11. 독립 Poisson 원시계수의 보수적 구간

확인된 원시계수에 한하여, 각각의 Poisson 평균을 Garwood 신뢰구간으로 평가하고 보수적인 동시구간을 적용한다.

Poisson mean lower(N) = 0.5 χ²_(2N, α_each/2), if N>0; else 0
Poisson mean upper(N) = 0.5 χ²_(2(N+1), 1−α_each/2)

전체 약 95% 커버리지를 보장하려면 두 계수 평균에 대해 각각 97.5% 양측 구간을 사용하고 Bonferroni 하한을 적용한다(독립성은 Poisson 모델에 포함). 총/배경의 단위시간 평균 구간을 뺀 뒤 K로 나눈다. 이 방법은 K와 S를 정확히 안다는 조건부이며, 교정·거리·재질오차를 포함하지 않는다. 배경 추정치가 상대적으로 크면 하한이 음수일 수 있다.

12. Monte Carlo 분포전파 — 사후확률과의 구분

  1. 관찰된 총/배경계수율을 각각 Poisson 평균의 plug-in 추정값으로 사용하여 반복 계수자료를 생성한다.
  2. 유효응답 K와 면적 S는 양수 로그정규 분포로 변동시킨다. 두 로그정규 변수의 정상표준 잠재변수에 지정한 상관 ρ를 적용한다.
  3. 배경변동을 정규분포로 추가하고 음수 배경은 0으로 제한한다.
  4. 반복마다 a=(N_g/t_g−N_b/t_b)/(K S)를 계산하여 2.5%, 50%, 97.5% 분위수를 표시한다.

중요: 이는 관측계수를 평균으로 대입한 모수적 재표집/모형 반복 분포이지, 방사능 참값의 베이지안 사후분포가 아니다. 기준 초과 표본의 비율은 모형 반복 초과분율이며 실제 P(오염도 > 기준 | 측정) 또는 규제상 합격/불합격 확률이 아니다. N_g >30 등의 큰 평균에서는 경량 Poisson 샘플러가 정규근사 난수를 사용하는 것을 유의한다.

13. 핵종·단위 변환과 모델의 분리

SI/비SI 예제:

1 Bq = 1 disintegration/s
1 Ci = 3.7×10¹⁰ Bq (exact conventional conversion)
1 Gy = 100 rad
1 Sv = 100 rem
1 cps = 60 cpm
1 Bq/cm² = 10000 Bq/m²
1 Bq/cm² = 6000 dpm/100cm²

Gy와 Sv는 정의가 서로 다른 물리량이다. Sv=Gy×상수라는 무조건 변환은 성립하지 않으며 입자 종류·조직가중치 등 모델이 필요하다. cpm→Bq 역시 핵종·방출률·계기·효율·기하조건에 따라 별도의 교정 응답이 필요하다.

14. 내장 검증과 실제 검증의 차이

  • 수학적 단위시험: 기본 계수환산, MDA 계산, Poisson 꼬리확률, 정확 2표본 검출력, 보수적 계수구간, 모의 공간역산, 단위 환산을 검사한다.
  • 브라우저 기능시험: 비밀번호 확인, 360/390px 모바일 메뉴, 계산값 갱신, 가상격자·잔차표, 가이드 링크, 데이터 내보내기를 검사한다.
  • 미완료 검증: 실제 GM 팬케이크 교정표와의 비교, 핵종·재질·거리·검출기 시정수별 검증, 현장별 스캔 검출한계 확증, 공식 ISO 11929/7503 조항별 검증, 인체피부 측정 효율의 실험 평가.
